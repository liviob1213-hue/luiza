# Portfolio - Studio Luzi Santana

Coloque aqui as fotos dos serviços realizados.

## Formatos aceitos
- `.jpg`, `.jpeg`, `.png`, `.webp`

## Como adicionar
Basta copiar as imagens para esta pasta. O site carregará automaticamente as imagens listadas no arquivo `index.html` na seção de portfólio.

## Recomendações
- Use imagens com boa resolução (mínimo 800x800px)
- Fotos em formato quadrado ficam melhores na galeria
- Nomeie os arquivos de forma descritiva, ex: `alongamento-gel-francesinha.jpg`
